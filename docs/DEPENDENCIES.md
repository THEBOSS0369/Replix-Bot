# Required Dependencies

Add these dependencies to your `package.json`:

## Production Dependencies

```json
{
  "dependencies": {
    "@anthropic-ai/sdk": "^0.34.0",
    "uuid": "^10.0.0",
    "dotenv": "^16.4.5"
  }
}
```

## Dev Dependencies

```json
{
  "devDependencies": {
    "@types/uuid": "^10.0.0",
    "tsx": "^4.19.2"
  }
}
```

## Installation

Run:
```bash
npm install @anthropic-ai/sdk uuid dotenv
npm install -D @types/uuid tsx
```

Note: `@supabase/supabase-js` is already in your project, so no need to add it.
